# SkillSwap

A React + Vite interactive frontend starter for a peer-to-peer student skill exchange platform.

## Run locally

1. Install Node.js (LTS) from https://nodejs.org/
2. Extract this folder and open it in VS Code.
3. Open Terminal > New Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Included interactions

- Responsive landing page and navigation
- Sign-up and login demo flows
- Browser-local account persistence
- Explore students with live search and category filters
- Student profile modal and skill exchange request flow
- Dashboard with request history
- Toast feedback

## Important

This is a frontend prototype. Authentication is a local browser demo, not secure production authentication. Student profiles are sample data. Requests are saved in localStorage on the current browser. A production release needs a backend, database, real authentication, authorization, and moderation/privacy controls.
